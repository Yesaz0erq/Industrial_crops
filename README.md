# Industrial Crops · 尖端工业化农作物

[下载](https://github.com/Yesaz0erq/Industrial_crops/releases) · [问题反馈](https://github.com/Yesaz0erq/Industrial_crops/issues) · [MIT 许可](LICENSE)

## 从农田到工厂

- **培育作物**：种植工业作物，研究品质与遗传，使用分析和改造设备推进育种。
- **连接设备**：用管道、储存柜和网络终端管理物品与流体，支持远程访问。
- **收集罗贝饰品**：在村庄宝箱中寻找数十种罗贝，获得战斗、探索或生存能力。

## 元件统一制作（本地 C2）

全部25种元件、基板和升级套件统一由元件编程设备制作，不能在工作台或其他机器制造；具体原料与数量见JEI。

先用4个金锭、2个红石、1个红石火把、1个比较器和1个合成器在工作台制作编程设备，无需已有元件。再在编程设备中用2个比较器、1个红石火把和1个金锭制作元件基板；套件基板将金锭换为铁锭。

配方包括：两种基板；基础储存组件、强化储存组件、10K存储元件及工业存储元件 I–IV；加速元件 I–IV；自动元件、制导元件、速射元件、威力元件、挖掘升级元件及两种维度升级元件；AP扩建组件 I–III；金与水晶钢升级套件。原分级升级关系保留，最多使用5个输入槽。

金升级套件仅用于基础操纵设备，水晶钢升级套件用于生物能发电设备。基础/强化储存组件、10K存储元件和AP扩建组件 I–III也在编程设备制作。工业存储与加速元件的分级升级路径保持不变。强化储存组件保留可用的模组铜箱选项；未安装任何铜箱时，使用普通箱子。

自动元件消耗3个比较器；编程设备会先确认全部材料和输出空间，再扣除材料。加速元件 III、IV分别需要2个不可堆叠的前级元件，请分开放入输入槽。史莱姆培养设备不再制作元件基板，其他史莱姆资源及天然掉落保留。

## AP 农场与牧场：地表结构（本地 C2）

| 安装组件 | 占地（格） | 相当于区块面积 |
| --- | --- | --- |
| 无 | 16×16 | 1 |
| AP扩建组件 I | 32×16 | 2 |
| AP扩建组件 II | 32×32 | 4 |
| AP扩建组件 III | 48×48 | 9 |

占地无需对齐区块边界，仅最高扩建等级生效。升级后必须自行补齐新尺寸的结构；结构不完整或范围未全部加载时停止运行。六个升级槽支持加速元件、威力元件、自动元件、维度升级元件和AP扩建组件，维度升级元件加载的是实际占地涉及的区块。

### 坐标约定

u沿控制器正面朝向的顺时针方向增加，v向背后增加。农场以控制器高度为h=0，控制器位于(W/2-1,0,0)，作物在h=0、种植土壤在h=-1。牧场以控制器下一格为h=0，控制器位于(W/2-1,1,0)，正下方h=0必须是栅栏；栅栏门在(W/2,0,0)，即从入口外看控制器在门右侧栅栏上方。

六个升级槽支持加速元件、威力元件、自动元件、维度升级元件和AP扩建组件。仅需安装一个最高等级AP扩建组件，并自行补齐完整新结构。两种设施均不检查h<0的固定构件；地基与地面检查加载后自动通过。范围内至少有一处源水。

### 农场：玻璃蔬菜大棚

占地W×D；农场控制器在(u,h,v)=(W/2-1,0,0)。旁边(W/2,0,0)放两格高的任意木门。h=0是作物平面，种植时其下h=-1需实际耕地；成型不检查地下或整片地面的材料。

不要求AP钢外壳地基、全铺耕地、木板通道或预设水渠。可自行安排种植区与自然土层；原版耕地湿润规则仍适用。占地内h=-1..6至少一处源水即可通过用水检查，含水方块也算，流水不算。后部(2,0,D-3)放堆肥桶，(3,0,D-3)放工作台。

每16格宽为一组坡顶。r=u除以16的余数，屋顶高度H=3+向下取整[min(r,15-r)/2]，边缘h=3、屋脊h=6。屋顶覆盖W×D；v=0、8、16……和D-1的拱肋用AP钢框架，其余用玻璃。

拱肋与u=0、W-1、16、32……相交处，从h=0到H-1放框架柱；中央u=W/2处跳过内部竖柱。外周其余墙面用玻璃封到H-1，保留控制器和木门。内部保持净空，水源不得替代必需构件或以含水实心方块堵塞通行。

### 牧场：带小雨棚的露天养殖场

牧场以控制器下一格作为h=0，动物、栅栏门和围栏位于此层。控制器在(W/2-1,1,0)，正下(W/2-1,0,0)放任意栅栏；旁边(W/2,0,0)放任意栅栏门。从入口外看，控制器就在门右侧栅栏上方，门上方留空。

外周h=0用任意栅栏围住，只在门位置留入口。不检查h<0的任何固定构件，不要求AP钢外壳地基、统一木板或草土地面；可保留自然地面。占地内h=-1..3至少一处源水即可，含水方块也算，流水不算，无需固定饮水池。

7×7小雨棚位于u=W-8..W-2、v=D-8..D-2，四角h=0..2用栅栏作立柱，h=3用任意木板、木台阶或木楼梯铺顶；地面不作材料要求，其余牧场保持露天。

喂食槽位于h=0、u=W-8..W-4、v=D-7..D-5；5×3外圈放木台阶，中间3格放干草块。堆肥桶放(W-6,0,D-4)。h=0..2除设施和立柱外保持净空，可保留草；含水实心方块也不能堵塞净空。

饲料放控制器饲料栏，槽内干草仍是必需构件。每种动物上限为8、16、32或64只。扩建后补齐新围栏，并将雨棚和喂食区移到新的后边界；水源在扩大后范围内任意合适位置即可。

### 检查、源水与替换材料

打开控制器投影页并启用全息投影。青色方块为待补构件，红框为错误材料或需清空的位置；附近最多显示256个提示，走近远处可继续查看。投影不再要求任何地下构件或指定水渠、水池。

九项状态中，“无需地基”和“自由地面”在范围加载完成后自动通过；其余检查框架、围护、棚顶、入口、配套设施、净空以及至少一处源水。农场水源高度h=-1..6，牧场h=-1..3；含水源水可用，流水不算。范围未加载完整时停止工作。

材料按标签替换：玻璃支持普通和16色染色玻璃及玻璃板，不含遮光玻璃；木门、栅栏、木板、木台阶、木楼梯可混用木种。含水构件仍须满足其原本材质与净空要求。

农场仅在h=0作物平面工作，播种点为空气且其下是耕地才播种；不检查整片地下地面。牧场只管理内部动物并收集内部掉落物，围栏外和命名、驯服动物不受影响。

AP扩建组件 I在编程设备中使用AP结构钢板×4、AP钢框架×2、元件基板×2、维度升级元件×1制作；II、III分别消耗前级AP扩建组件×1、AP结构钢板×4、AP钢框架×2与晶体锭×2。游戏内手册与本说明使用同样的结构坐标。

## 从源码构建

本目录 `Industrial_crops-neoforge-1.21.1-C2` 是可独立构建的 NeoForge 1.21.1 C2 工程，使用 Java 21。其他加载器应使用其对应的独立 C2 工程；本工程仅包含完整源码、实际使用的运行资源、构建配置、Gradle Wrapper、说明与许可文件。

进入目标工程，使用上表对应的 Java 版本执行：

```sh
# Linux / macOS
./gradlew build
```

```powershell
# Windows
.\gradlew.bat build
```

首次构建需要联网下载依赖。成品位于所选工程的 `build/libs/`。启动开发客户端使用 `runClient`；添加 `-PwithoutCurios=true` 可在不加载 Curios 的情况下运行。
