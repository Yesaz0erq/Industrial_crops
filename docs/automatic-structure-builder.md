# 自动建造装置

支持 AP 农场、AP 牧场、AP 史莱姆农场的 16×16、32×16、32×32、48×48 结构。

## 制作

工作台配方：

```text
铁锭       活塞       铁锭
红石       元件基板   红石
铁锭       青金石     铁锭
```

## 使用

1. 准备平整地面并清空上方空间，将装置放在目标建筑前方。目标控制器位于装置背面 3 格处，建筑继续向后延伸；牧场控制器会自动抬高 1 格。
2. 右键打开界面，点击左上角选择结构、点击右侧尺寸按钮切换尺寸。材料清单会按实际缺少的方块更新，已有合格结构可以复用。
3. 将清单材料放进四页材料仓库。控制器、扩建元件、水桶也计入清单。创造模式无需材料。
4. 可将加速元件 I–IV 装入右下方的独立插槽，只取最高等级。
5. 点击“开始建造”。成功放置后才扣除对应材料，水桶使用后返还一个空桶；扩建元件自动装入控制器。

| 速度元件 | 建造速度 |
| --- | --- |
| 无 | 每 0.5 秒 1 块 |
| I | 每 0.25 秒最多 8 块 |
| II | 每 0.5 秒一组区块 |
| III | 每 0.1 秒一组区块 |
| IV | 16×16 一次建好；更大结构每游戏刻一组区块 |

“区块组”以世界实际 16×16 区块划分，同一批次按高度从下到上放置。最大档只对小尺寸一次完成，避免大结构集中建造造成卡顿。

“停止”会保留已建部分和剩余材料。卸载、重启或建造者离线后会安全停止，下次补齐材料并点击开始即可续建，不会重复扣除已经完成部分的材料。建造中材料和升级槽锁定。

装置不负责整体平地、铺土或耕地。农场和牧场会在地下 1 格放置一个水源，水源孔的底部和四周必须封闭；史莱姆农场会安装下沉的 3×3 黏液块垫。只有这些位置的天然泥土可以替换。其他坚固方块、方块实体或被占用的内部空间会阻止建造。

目标区域需要处于加载范围、世界高度和边界内，并且具有建造权限。装置不会主动强制加载区块。
