# 自动建造装置

支持 AP 农场、AP 牧场、AP 史莱姆农场的 16×16、32×16、32×32、48×48 结构。

## 制作

在水晶钢工作台按下图摆放材料，每格 1 件，无需流体。圆点表示空格。

```text
· 钢 钢 钢 ·
钢 塞 侦 塞 钢
· 红 壳 红 ·
· · 自 · ·
· 钢 钢 钢 ·
```

钢为 AP 结构钢，塞为活塞，侦为侦测器，红为红石粉，壳为 AP 钢外壳，自为自动元件。

## 使用

1. 已有 AP 农场、牧场或史莱姆农场控制器时，将装置紧贴控制器，建议放在入口朝外的一侧。装置自动读取控制器的类型、朝向和已装的扩建元件。相邻多个控制器时会停机。
2. 右键打开界面。控制器没有扩建元件时，可选择四档尺寸之一。若装置周围没有控制器，可手动选择类型和尺寸，新控制器将建在装置背面 3 格处。牧场的新控制器会抬高 1 格。
3. 右侧列出本次施工要用的材料和缺口。将缺少的材料放入左侧四页仓库；悬停材料可查看库存和剩余需求。补齐后，底部会显示“准备就绪”。创造模式无需材料。
4. 可将加速元件 I–IV 装入右下方的独立插槽，只取最高等级。
5. 查看“预计拆除”的格数，再点击“开始建造”。右下角显示已完成和总施工步数。清障不扣建材，放置成功后才扣料。水桶使用后返还一个空桶，扩建元件自动装入控制器。

| 速度元件 | 建造速度 |
| --- | --- |
| 无 | 每 0.5 秒 1 块 |
| I | 每 0.25 秒最多 8 块 |
| II | 每 0.5 秒一组区块 |
| III | 每 0.1 秒一组区块 |
| IV | 16×16 一次建好；更大结构每游戏刻一组区块 |

“区块组”以世界实际 16×16 区块划分，同一批次按高度从下到上放置。最大档只对小尺寸一次完成，避免大结构集中建造造成卡顿。

“停止”会保留已建部分和剩余材料。卸载、重启或建造者离线后会安全停止，下次补齐材料并点击开始即可续建，不会重复扣除已经完成部分的材料。建造中材料和升级槽锁定。

装置会拆除蓝图内需要替换或留空位置的障碍方块，保留已符合要求的方块。建造前可先移走范围内想保留的设施。基岩等生存模式不可破坏的方块会阻止建造。请为建筑准备稳固地面。农场和牧场的水源位于地下 1 格，其底部和四周需要封闭。史莱姆农场的 3×3 黏液块垫会下沉安装。

目标区域需要处于加载范围、世界高度和边界内，并且具有建造权限。装置不会主动强制加载区块。
