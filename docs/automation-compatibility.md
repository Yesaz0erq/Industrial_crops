# 物品物流与自动化

适用于 Industrial Crops C4 的 Forge 1.20.1 和 NeoForge 1.21.1。把物品管道接到机器本体。其他模组的管道需要支持对应加载器的物品处理接口。表中槽号从 0 开始，指管道看见的槽位。

## 常用接法

| 设备 | 管道可以送入 | 管道可以取出 |
| --- | --- | --- |
| AP 农场、AP 牧场、AP 史莱姆农场 | 0–8 是种植、饲养或养殖输入格，沿用各设备的物品筛选 | 9–17 是产物格。扩建和加速槽由玩家操作 |
| 自动建造装置 | 空闲时可填充 0–107，即四页材料仓库 | 空闲时可取回材料和使用后留下的空桶。建造过程中仓库锁定，速度槽独立 |
| 基础控制设备 | 所有面都连到已加载且相连的铜质基础存储组件，每个组件提供 54 格 | 从同一组物品格取出。拆开中间组件后，只能访问仍与控制器相连的部分 |
| 强化控制设备 | 相连铁质强化存储组件的各页，每个组件提供 54 格 | 与控制器界面共用库存。移走所有外部组件后，重新使用内部已解锁的存储格 |
| 存储组件、进阶工业存储设备、可扩展存储设备 | 将货物直接送进组件或设备已解锁的储物格 | 可取出已有货物。容量元件和维度升级在设备界面中管理 |
| 无线物流传输设备 | 完成配对，将收货端设为输入模式。此端接受送入缓冲格的物品 | 在另一端切换为输出模式后抽取缓冲格。向外送货和反向补料需要相应的端点方向 |
| 管道分拣器 | 输入缓冲接收送入物品，按各方向的过滤条件分发 | 到相应目的容器取货。界面中的过滤样品用于设定条件 |

## 加工设备的槽位

下表按源码中的物品接口归纳。判断投入物时仍使用机器自己的配方和物品规则。

| 设备 | 输入与输出 |
| --- | --- |
| 作物压缩机、超级压缩机、史莱姆培养设备、材料硬化设备、矿脉数据采集器 | 向 0 号格供料，从 1 号格取产物。超级压缩机把送入的作物计入内部缓冲 |
| 基础农作物转化设备、西瓜改造设备 | 前者用 0–2 号材料格，成品在 3 号格。后者用 0、1 号输入格，成品在 2 号格 |
| 搅拌器、处理器编程设备 | 搅拌器有七个原料格和一个袋子格，产物在 8 号格。编程设备有五个输入格，产物在 5 号格 |
| 电炉、超高压因弗锻造炉 | 电炉三组通道使用 0–2 输入、3–5 输出。锻造炉使用四个输入格和一个输出格 |
| 集成熔炼炉 | 投入当前有效页的工作格。可取出已完成的产物和不能继续熔炼的物品 |
| 超级作物培育器 | 0 号格放作物，1–3 放材料，4、5 分别取主产物和副产物 |
| 自动养殖设备、自动种植设备 | 养殖设备有九格输入和九格输出。种植设备有 27 个种子输入格，种下的作物出现在世界中 |
| 史莱姆转化设备、提取设备、作物分析设备 | 转化设备接收转化材料，史莱姆由装置释放。提取设备接收原料并从流体接口输出。分析设备可送入和取回分析样本 |
| 地形处理设备、合成处理设备 | 地形设备的物品接口含一个填充材料输入格和九个回收输出格。合成处理设备提供九个产物输出格 |
| 物质数据化设备、数据复制设备、物质重构设备 | 数据化设备接收 27 格实物并上传数据。复制设备在网络中增加数据数量，可装入其允许的元件。重构设备从成品格输出实物 |
| 爆炸土豆发射器、数字微缩森林、生物能设备 | 发射器开放弹药槽。微缩森林只接收合适的元件。生物能发电、反应和焚烧设备按其燃料槽接收物品，能源和残渣按设备各自机制传输 |
| 悖论钢锻炉 | 将两种配方材料送入对应输入槽，从成品槽取出钢锭 |

## 临时合成格和数据界面

水晶钢工作台的 5×5 合成格随玩家打开界面创建，关闭后返还剩余材料。流体管道可以给工作台的储罐供液。基础机械手的合成材料来自玩家背包及相连的存储组件。

物品网络管理终端显示数据条目。管道可以连接物质数据化设备送入实物，连接物质重构设备取出实物。水晶钢火箭发射装置、卫星控制装置和信号接收装置的界面显示状态或控制指令。物品栏中打开的便携容器也没有可供方块管道连接的位置。

## 验证记录

两个版本各自在隔离服务端通过 100 项机器物品接口检查、82 项农场与物流检查，以及 17 项跨区块仓库专项检查。另逐面查询了 86 种已注册方块的能力，其中也包括没有物品槽的方块。

| 实测场景 | 观察结果 |
| --- | --- |
| AP 农场采收 | 实测未装自动元件时可收获成熟小麦、胡萝卜、甜菜、火把花和投手植物。双格投手作物结算一次，工业瓜采收后保留瓜茎和果实的遗传数据。产物放不下时作物留在田里 |
| 管道与无线物流 | 普通物品管道能给农场供种和抽取产物，AP 导管能传输，配对的无线设备能在农场和箱子之间按配置双向送料 |
| 仓库控制器 | 基础和强化控制器均可访问所连组件。拆开后换入新组件，缓存的端口跟随新连接。AP 导管会跳过指向同一库存的控制器和组件 |
| 跨区块仓库 | 保持旧端口引用，断开长链远端区块后只显示仍加载的仓页，查询本身不会重新加载远端区块。自然卸载并重载后，远端仓的 23 颗钻石和另一台强化控制器内部的容量元件、19 颗绿宝石均保留 |
